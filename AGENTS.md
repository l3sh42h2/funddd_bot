# funding_bot — инструкции для агентов (Codex)

ОБЯЗАТЕЛЬНО перед любой задачей в этом проекте прочитать и соблюдать `docs/COORDINATION.md`: над ботом работают два
агента (Codex и Claude), задачи и ревью назначает владелец, о пересечениях с задачами другого агента — сообщить риск и
ждать решения владельца, выкат — только общим механизмом, секреты — никогда в Git.

Перед новой задачей: `git fetch origin`, затем `git show origin/main:docs/COORDINATION.md` и просмотр новых
патчноутов в main/рабочих ветках. Это только чтение: чужую рабочую копию не менять. Устаревшая копия правил
не отменяет новые решения владельца. Согласованные правила эффективности FUNDING — §6; учёт изменений — §7.

## Эффективность — 15.09.2026, прямое указание владельца

Работать эффективно по общему расходу и времени. Один исполнитель по умолчанию;
делегировать только самостоятельные ограниченные части, не дублировать работу.
Дорогой основной чат не должен выполнять рутинную сборку и повторный опрос статусов
под видом экономии на помощниках. Явно сообщать фактическую модель основного чата.
Не расширять scope; большие этапы делить на принимаемые результаты. Профильные
проверки в разработке, полный набор на фиксированном кандидате; не повторять без
новой причины и не отменять денежные инварианты. Статусы собирать скриптом.
Расход подтверждать журналами, разделяя новый ввод/кеш/вывод и не выдавая их сумму
за фактическое списание подписки. Назначенный владельцем финальный ревьюер этого
common-пакета — Claude; проверки помощников его не заменяют.
