# M1 — реализовано в рабочей ветке

Основа: M0 (a976bec + receipt 0f88fd7). Боевой код и сервисы не изменялись.

- core/bootstrap.py запускает торговлю без TG_BOT_TOKEN/getMe/webhook/poller.
- core/commands.py — совместимый контроллер прежних команд; те же Desk/Engine и SOL/EVM исполнители.
- ipc/protocol.py: Unix socket, фактический UID peer, версии, ограничение кадра 1 MiB, 16 клиентов, таймаут 5 с.
- core/journal.py: additive core_* inbox/outbox/schema gate. Приём → durable request + legacy offset в одной
  транзакции. Повтор ключа возвращает статус; другой payload под тем же ключом отказан. После рестарта queued/running
  становятся interrupted, а фактические торговые attempts восстанавливаются прежним reconcile без авто-входов.
- Две очереди обработки: локальные управляющие действия и медленные планы. «Стоп» не ждёт котировки плана.
- Версия настроек фиксируется до котировки, план/spec/nonce/состояние связаны fingerprint; изменившееся подтверждение
  отказано. CAS nonce/TTL/owner и существующая проверка исполнителя остаются.
- Уведомления durable, подтверждения доставки переживают потерю связи. Exactly-once Telegram не обещается;
  повтор уведомления не создаёт заявку. Привязка message_id плана сохраняется атомарно с delivery ack.
- Один execution flock для core и обновлённого legacy trader, удерживается до завершения execution thread.
- Interface имеет собственный offset/delivery state и не подтверждает приём команды до durable acceptance core.
- Drain принимает только безопасные команды, но НИКОГДА не является разрешением переключения в M1/M2:
  safe_to_switch=false, полный gate восстановления/schema/artifact добавляется M5.

Проверки: tests/test_migration_m1.py (включая два настоящих процесса, отсутствие TG token, повтор команды,
остановка при котировке, устаревшая конфигурация, schema gate, потеря ответа и перезапуск интерфейса).
Дополнительно прежние tests/test_tg.py, tests/test_sol_c3_bot.py и полный набор сохраняют поведение исполнения.
Чистые legacy-форматтеры сообщений остаются внутри compatibility слоя до M3/M4; Telegram API и web в core не
импортируются. Это не объявление завершения M3/M4 либо полной унификации торгового координатора.
