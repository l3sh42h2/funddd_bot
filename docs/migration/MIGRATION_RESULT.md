расхождений проекций, но без доказательства полного покрытия исходных данных.

## Граница этого релиза

Это разрешённый ТЗ промежуточный релиз с проверенной совместимостью. Legacy EVM
execution/recovery сохранён внутри нового core. Он не объявляется полной заменой
денежного ядра общими адаптерами.

Для завершения M4 остаются интеграция общего EVM/spot execution, корректное
связывание legacy-записей с account scope и доказательство полноты ledger/history,
а также оставшиеся сквозные критерии общего координатора и матрицы приёмки.
Resize и SL остаются отдельным следующим патчем после завершения миграции.
Откат кода должен учитывать текущую авторитетную БД и reader compatibility;
возврат старой БД поверх текущего состояния недопустим.
